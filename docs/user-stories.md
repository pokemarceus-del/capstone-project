# AquaFlow user stories

These initial stories cover all four roles named in milestone M0. They are domain-discovery
artifacts, not claims that the workflows are already implemented.

## Admin

1. As an Admin, I want to create staff users and assign roles so that access matches job duties.
2. As an Admin, I want to suspend a staff account and review security events so that compromised
   access can be contained and investigated.
3. As an Admin, I want to configure zones, routes, and reader assignments so that field work is
   geographically organized.
4. As an Admin, I want to review an audit trail of sensitive changes so that operational actions
   are accountable.

## Billing Officer

5. As a Billing Officer, I want to find accounts by customer, zone, status, and address so that I
   can resolve account questions efficiently.
6. As a Billing Officer, I want to review flagged readings with previous readings and evidence so
   that I can approve, override, or reject them with a reason.
7. As a Billing Officer, I want to preview a bill run and its exceptions before issuing bills so
   that errors can be corrected before customers are charged.
8. As a Billing Officer, I want to issue immutable bills using the tariff version effective for
   the billing period so that each charge can be audited later.
9. As a Billing Officer, I want to record an over-the-counter payment against an account so that
   the ledger reflects funds received.
10. As a Billing Officer, I want to issue a reasoned adjustment instead of editing an issued bill
    so that the financial history remains auditable.

## Meter Reader

11. As a Meter Reader, I want to see only my assigned route and its stops so that I work on the
    accounts I am authorized to visit.
12. As a Meter Reader, I want to capture a reading, date, and required photo for a stop so that
    evidence is linked to the correct meter and period.
13. As a Meter Reader, I want to record no-access and other exceptions so that the system can
    follow the estimation or review process rather than losing the stop.
14. As a Meter Reader, I want to queue route readings while offline and synchronize them later so
    that poor connectivity does not block field work.

## Customer

15. As a Customer, I want to verify my identity and view only my own service accounts so that my
    personal and billing information remains private.
16. As a Customer, I want to view bills, prior usage, and downloadable bill documents so that I
    can understand how an amount due was calculated.
17. As a Customer, I want to pay a bill and see pending versus confirmed status so that I know
    whether the payment was received.
18. As a Customer, I want to manage notification preferences and receive payment/bill updates so
    that I can stay informed through my chosen channels.
